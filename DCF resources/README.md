# DCF resources

CFI templates populated with **Fair Isaac Corp (FICO)** historicals and base-case projections.

## Files

| File | Source page | Contents |
|---|---|---|
| `CFI_DCF-Model.xlsx` | [CFI DCF model](https://corporatefinanceinstitute.com/resources/financial-modeling/dcf-model-template/) | FICO assumptions, FY26–30 EBIT/D&A/NWC, WACC, debt/cash/shares |
| `CFI_3-Statement-Model-Complete.xlsx` | [CFI 3-statement case study](https://corporatefinanceinstitute.com/resources/financial-modeling/case-study-3-statement-model-template/) | FY21–25 history + FY26–30 forecast (simplified mapping) |

## Units / sources

- Figures in **$ thousands** (except share price)
- Historicals: SEC EDGAR FY2025 10-K / companyfacts
- DCF net debt / shares: 10-Q ended 2026-06-30 + Yahoo Finance
- Yellow cells with blue font are editable inputs

## Caveats

The CFI 3-statement template only has Cash / AR / Inventory / PP&E assets and AP / Debt liabilities, so FICO goodwill, deferred revenue, buybacks, and SBC are not fully modeled. Equity is a balancing plug on the simplified balance sheet.
